📖 使い方

🎸 TUNER（チューナー）

各弦のボタンをタップするとその弦の基準音が鳴ります。音を聞きながらギターのペグを回してチューニングを合わせてください。

  • ELECTRIC：エレキギター向けのサウンド
  • ACOUSTIC：アコースティック向けのやわらかい音
  • FADE：音が自然にフェードアウト
  • SUSTAIN：音が長く伸びる
  • ALL STRINGS：全弦を順に鳴らす
  • CODE : E / CODE : A：コードの構成音をストローク風に鳴らす（チューニングに連動して自動変化）
  • 音が鳴っている弦はアニメーションで振動します

🎵 METRONOME（メトロノーム）

▶ START をタップするとメトロノームが動き始めます。

  • スライダー：BPMを調整（40〜220）
  • − / +：1ずつBPMを増減
  • 拍子ボタン：2/4〜8/4から選択
  • TAP TEMPO：リズムに合わせてタップするとBPMが自動計算
  • 音色：設定メニューから5種類の音色を選択できます

🎼 CHORD FINDER（コード検索）

ROOT（ルート音）と TYPE（コード種類）を選ぶと、ローポジションのフォームがダイアグラムで表示されます。

  • ✕：弾かない弦
  • ○：開放弦（フレットを押さえない）
  • ●：フレットを押さえる位置
  • フォームボタン（E shape / A shape など）：バレーコードのフォームに切り替え。もう一度タップすると解除してローポジションに戻ります
  • NOTES：コードの構成音
  • INTERVALS：度数（1=ルート、3=3度、5=5度など）

⚙ 設定

右上のメニューボタンから設定を開けます。

  • 言語：日本語・English・中文・한국어
  • メトロノーム音色：5種類から選択
  • テーマ：Dark / Light / Ocean
  • グロー演出：シアンの発光エフェクトのON/OFF
🔒 プライバシーポリシー

情報の収集について

本アプリはユーザーの個人情報を収集しません。すべての操作はお使いの端末内で完結します。

広告について

本アプリはGoogle AdSenseによる広告を表示する場合があります。広告配信のためCookieが使用されることがあります。

アクセス解析について

Google Analyticsを利用してアクセス状況を分析する場合があります。収集されるデータは匿名であり、個人を特定するものではありません。
