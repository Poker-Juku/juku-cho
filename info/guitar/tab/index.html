タブ譜の読み方

音符が読めなくても大丈夫。ギターには「タブ譜（TAB譜）」という、押さえる場所がそのまま分かる楽譜があります。仕組みはとてもシンプルです。

01タブ譜って何？

タブ譜は、ギターのために作られた楽譜です。6本の横線がギターの6本の弦を、線の上の数字がフレット（押さえる場所）を表します。「どこを押さえて弾くか」がそのまま描いてあるので、五線譜が読めなくても曲を弾けます。

6本の線＝6本の弦。いちばん上が細い1弦、いちばん下が太い6弦です。
ここが最初のつまずきポイント。 タブ譜の一番上の線は、ギターを構えたとき下側にある細い弦（1弦）です。上下が逆に感じますが、慣れれば自然に読めます。

02数字＝フレット。「0」は開放弦

線の上の数字は、その弦の何フレットを押さえるかを表します。3なら3フレットを押さえて鳴らす、という意味です。数字が 0 のときは、どこも押さえずに弦をそのまま鳴らします（＝開放弦）。

左から右へ時間が流れます。数字の位置＝弦、数字＝フレット。

03縦は「同時」、横は「順番」

数字が縦にそろっているときは、その弦をいっしょに鳴らす＝コードです。数字が横に並んでいるときは、左から順番に1音ずつ鳴らす＝メロディやフレーズになります。

左：Emコードを一度に鳴らす。右：1音ずつ弾いていくメロディ。

弦が合っていないと、正しく読んでもズレます

タブ譜を試す前に、まずチューニングを。ブラウザですぐ合わせられます。

04覚えておきたい記号

タブ譜には、弾き方を表すアルファベットや記号が添えられることがあります。よく出るものだけ押さえておけば十分です。用語をタップすると辞典で詳しく確認できます。

h
ハンマリングオン弾いた後、指で叩いて次の（高い）音を出す
p
プリングオフ押さえた指を引っかけて離し、低い音を出す
/ \
スライド押さえたまま弦を滑らせて音程を移動する
b
チョーキング（ベンド）弦を押し上げて音程を上げる、ギターの泣きの表現
~
ビブラート音を細かく揺らして伸びと表情を加える
PM
ブリッジミュート右手側面を弦に軽く乗せ、音を詰めて刻む
x
ミュート音程を出さず「ジャッ」というリズム音だけを出す

05やってみよう：指ならしフレーズ

最後に、実際にタブ譜を読んで弾いてみましょう。細い弦（1弦・2弦）だけを使う、やさしい練習フレーズです。左から順に、ゆっくり1音ずつ。数字は押さえるフレットです。

1弦で 0→2→3、2弦で 0→2→3、また1弦に戻って 2→0。弾けたら少しずつ速く。

読めましたか？ これがタブ譜の基本のすべてです。あとは弾きたい曲のタブ譜を用意して、同じ要領で読んでいくだけ。分からない言葉が出てきたら、音楽用語辞典で確認しながら進めましょう。

分からない用語は辞典へ

楽典・コード・奏法・機材まで、検索してやさしく確認できます。
